# 💣 지뢰찾기 (Minesweeper Web App)

클래식 Windows 레트로 감성과 모던 다크 테마를 모두 지원하는 완성형 웹 지뢰찾기 게임입니다.

🌐 **온라인 플레이 (GitHub Pages)**: [https://ddikui.github.io/minesweeper/](https://ddikui.github.io/minesweeper/)

---

## 🎮 주요 기능

1. **클래식 & 모던 테마 전환 (🎨)**
   - **레트로 테마**: 윈도우 95/98 감성의 입체 베벨 버튼, 클래식 LCD 7세그먼트 디스플레이, 노란색 스마일리 버튼.
   - **모던 테마**: 세련된 다크 글래스모피즘 & 네온 블루 스타일.
2. **공식 표준 난이도 및 커스텀 모드**
   - **초급 (Beginner)**: 9×9 격자, 지뢰 10개
   - **중급 (Intermediate)**: 16×16 격자, 지뢰 40개
   - **고급 (Expert)**: 30×16 격자, 지뢰 99개
   - **사용자 지정 (Custom)**: 가로(8~40), 세로(8~30), 지뢰 수 자유 설정
3. **완벽한 게임성 & 편의 기능**
   - **첫 클릭 안전 보장**: 첫 클릭 시 절대 지뢰를 밟지 않으며, 시원한 빈 영역을 확정 개방합니다.
   - **코드 (Chording) 기능**: 이미 열린 숫자 칸을 클릭했을 때, 주변에 꽂힌 깃발 수가 일치하면 미확인 인접 칸들을 즉시 열어줍니다.
   - **효과음 (Web Audio API)**: 클릭, 깃발 꽂기, 코드 오픈, 지뢰 폭발음, 승리 팡파르가 외부 음원 파일 없이 순수 웹 오디오로 합성 재생됩니다. (상단 🔊 버튼으로 음소거 가능)
   - **승리 축하 콘페티**: 승리 시 화면 전체에 화려한 색종이 폭죽 애니메이션이 펼쳐집니다.
   - **최고 기록 저장 (🏆)**: 로컬 스토리지에 난이도별 최단 클리어 기록을 영구 보관합니다.
   - **모바일/터치 대응**: ⛏️ 파기 / 🚩 깃발 전환 스위치 및 터치 롱프레스(길게 누르기)로 손쉽게 깃발 설치 가능.
